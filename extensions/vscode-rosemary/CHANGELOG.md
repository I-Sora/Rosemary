# Changelog

ROSEMARY VS Code 拡張機能の主な変更は、このファイルに記録されます。

## 0.1.0

一般公開準備のための初期リリースです。

### 追加

- `.rsmr` 言語登録とシンタックスハイライト。
- Meta、Graph、Blocks section を備えた ROSEMARY preview panel。
- Graph の pan、zoom、reset、solid line、dotted line、bold line、label、bidirectional line。
- editor と preview の両方における block folding support。
- editor と preview の scroll / cursor synchronization。
- block reference highlighting、hover summaries、jump-to-definition。
- `@include "file.rsmr"` project parsing。
- character、item、scene、relationship、state、unknown、question、answer、dialogue、annotation、tag、key-value attribute support。
- paragraph、nested list、numbered list、dialogue、annotation を含む multiline field block。
- multiline field block 内の list continuation に対する Enter と Tab editing helper。
- block reference highlight color と excluded block name の設定。
- Enter と Tab による list editing helper の無効化設定。
- PNG extension icon と `.rsmr` file icon。

### 補足

- ROSEMARY 構文はまだ 1.0 前の段階であり、今後変更される可能性があります。

# Changelog

## English

All notable changes to the ROSEMARY VS Code extension will be documented in this file.

## 0.1.0

Initial public-preparation release.

### Added

- `.rsmr` language registration and syntax highlighting.
- ROSEMARY preview panel with Meta, Graph, and Blocks sections.
- Graph pan, zoom, reset, solid lines, dotted lines, bold lines, labels, and bidirectional lines.
- Block folding support in both editor and preview.
- Editor and preview scroll/cursor synchronization.
- Block reference highlighting, hover summaries, and jump-to-definition.
- `@include "file.rsmr"` project parsing.
- Character, item, scene, relationship, state, unknown, question, answer, dialogue, annotation, tag, and key-value attribute support.
- Multiline field blocks with paragraphs, nested lists, numbered lists, dialogue, and annotations.
- Enter and Tab editing helpers for list continuation in multiline field blocks.
- Configurable block reference highlight colors and excluded block names.
- Setting to disable Enter and Tab list editing helpers.
- PNG extension and `.rsmr` file icons.

### Notes

- The ROSEMARY syntax is still pre-1.0 and may evolve.
